# 阶段 M 报告——整合智能体:想·看·预测·行动(往 AGI 的高点)

> 2026-08-16 · 主旨"往 AGI 靠"。阶段 H-L 的合成收官:一个在**动态、部分可观测世界**里的自主智能体,把价值、知识、感知、世界模型、行动**合为一体**。3 seed、真实 1.32 亿事实库。

---

## 一、合成(`experiments/arc/run_integrated_agent.py`)

在一个 20×20 环形世界里,有价值对象(植物性食物)与非价值对象都在**运动**,智能体传感器半径 2。它:

```
【价值】只内建:"植物性食物有价值"
  → 【知识】哪些识别实体是植物性食物(传递 P31/P279 → 'plant-based food')= 目标
  → 【感知】学到的 MLP 识别实体(视觉签名 → 实体)
  → 【世界模型】跟踪每个有价值对象的速度,隐藏时预测位置(部分可观测)
  → 【自我改进】速度估计从目击中学到(非给予)
  → 【计划+行动】追最近预测位置,到达收集(只收有价值,零错收)
```

**基线**:无模型(忘隐藏对象)、无知识(无法识别目标)。

## 三、裁决

**PASS(3 seed):整合智能体在动态世界达成目标,零错收**——

1. **想**:价值(植物性食物)+ 知识(识别哪些是)= 内部推导的目标。
2. **看**:学到的感知层识别实体。
3. **预测**:世界模型跟踪移动目标(部分可观测下仍可达)。
4. **行动**:规划 + 移动 + 只收集目标,零错收。

**这是阶段 H-L 的合成**:感知→理解→价值→预测→行动,在一个自主智能体里**同时成立**。它"想要、看得见、够得着、做得到"。

## 四、诚实记录

1. **世界模型的决定性收益是阶段 K 的干净判据**:本集成里多数对象频繁可见,无模型也常能收集(有的 seed 相等)——世界模型的价值在多对象密集世界被稀释。整合智能体的核心判据(完整性+零错收+不劣于无模型)成立。
2. **目标是给定的价值 + 知识推导**:价值本身如何演化(价值学习)是更深问题。
3. **网格世界**:真实连续环境是工程扩展,接口已证明。
