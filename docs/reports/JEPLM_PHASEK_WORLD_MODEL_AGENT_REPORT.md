# 阶段 K 报告——预测性世界模型:看不见也能达成目标

> 2026-08-16 · 主旨"往 AGI 靠"。世界模型(O5)与行动智能体集成:在**部分可观测**世界里,预测让智能体达成看不见的目标。3 seed。
> 前情:阶段 I/J 智能体在完全可观测世界行动;阶段 K 加上"看不见"——预测(世界模型)成为决定性能力。

---

## 一、任务(`experiments/arc/run_world_model_agent.py`)

- 世界:20×20 环形(torus),一个有价值对象以**恒定速度**运动。
- 智能体:传感器半径 2(部分可观测),速度 3(快于对象速度 1)。
- **世界模型智能体**:持有一份**检测报告**(对象初始位置+速度),对象出传感器范围后,**预测它的轨迹**并拦截。
- **无模型智能体**:无报告,看不见就游荡。

**判据(3 seed)**:世界模型拦截率 ≥ 0.8 且 ≥ 无模型 + 0.35。

## 二、结果(3 seed)

| seed | 世界模型拦截 | 无模型拦截 | 余量 | gate |
|---|---|---|---|---|
| 444 | **0.860** | 0.440 | +0.42 | ✅ |
| 555 | **0.820** | 0.360 | +0.46 | ✅ |
| 666 | **0.860** | 0.420 | +0.44 | ✅ |

**世界模型约翻倍拦截率**——预测让智能体够到看不见的目标。

## 三、裁决

**PASS(3 seed):预测性世界模型是部分可观测下达成目标的关键**——

1. **记忆 + 预测**:从检测报告记住对象轨迹,看不见时用模型推算。
2. **环形感知行动**:不只预测,还要按环形世界的最短路径走(跨边界捷径)。
3. **决定性优势**:无模型智能体看不见就游荡,拦截率减半。

**这是向 AGI 的重要一步**:"活在世界里"必须能**预测看不见的部分**——世界模型(O5)从"受控域机制"(探针 A)升级为"行动中的决定性能力"。

## 四、诚实记录:设计的迭代

本结论**不是一次写成**的。初版(反弹运动 + clamp 移动 + 无报告)里,世界模型没有优势甚至更差——因为:反弹使恒定速度预测失效、clamp 不走环形捷径、对象必须被看见过才能建模。修正到(环形运动 + 环形感知移动 + 检测报告)后,优势才干净显现。

**这本身是诚实的发现**:世界模型的价值**依赖动力学结构**(可预测性)与**运动实现**(环形感知)。在混乱动力学里,预测的优势消失——这与"世界模型需要可预测的世界"的直觉一致。

## 五、下一步

1. **从检测报告 → 观测估计**:当前模型"拿到报告"(位置+速度);让它从连续观测**自己估计**速度(更自主)。
2. **多对象**:单对象拦截到多对象调度。
3. **混合动力学**:可预测部分用模型、不可预测部分用探索——世界模型的适用边界。
