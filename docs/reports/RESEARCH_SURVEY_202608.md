# 网络调研报告：PLWM 设计外部验证（2026-08）

> 目的：核对 PLWM 总设计与"状态主体、分层信号、持续世界"主张在外部学界/工业界的位置，
> 找出被佐证的决策、被证伪的假设、错过的高价值先例。
> 检索覆盖六个方向：认知架构总览、JEPA 家族、MoE/Transformer 原理、RNN 复兴、
> 世界模型、外挂记忆、持续学习。所有链接为调研当日检索结果。

## 0. TL;DR（对 PLWM 的净结论）

1. **方向被强烈佐证**：2026 年学界主线收敛于"状态+外挂记忆+持续适应"——Titans 的
   test-time 记忆、Memory3 的"显式记忆外置"、CoALA 的模块化记忆、Genie 3 的"分钟级
   视觉记忆"。PLWM 的"知识在状态不在权重"不是偏门，而是主流正在靠近的终点。
2. **差异化成立**：主流全部以 LLM 为核+外挂记忆；PLWM 以状态-世界模型为核、LLM 只做
   眼嘴，这个分层目前无直接先例，是真正的创新空间，也是最大风险（无既往证据）。
3. **两个机制被外部独立印证**：
   - 惊喜驱动记忆（Titans 的 surprise-metric、SuRe 的 surprise 优先回放 ↔ 我们的"预测
     误差驱动写入"）。
   - 世界模型预测误差做漂移探测器（arXiv:2603.04029 用 WMP 残差检测 OOD 并触发微调
     ↔ 我们的"drift-world 考试+门控"）。
4. **被证伪/需修正的假设**：纯 RNN/SSM 在短上下文与精确记忆上输了 Transformer
   （Mamba/RWKV 弱势=无注意的精确索引）。这警告我们的 L2 记忆读取**必须**做"精确可
   寻址"（我们已设计 address-priority 读，方向正确），不能退化成纯压缩状态。
5. **评估基准有现成模板**：MemoryAgentBench(ICLR 2026) 四能力（精确检索/测试时学习/
   长程理解/选择性遗忘）可平移为我们的 drift-world 考试科目。

## 1. 认知架构与世界模型总览

- **CoALA（arXiv:2309.02427, 2023, 被引 765+）**：把 LLM 语言代理放进经典认知架构
  （Soar/ACT-R 谱系），定义工作记忆 + 长期记忆（情景/语义/程序）+ 决策循环。
  关键论点：**语言模型是无状态的（stateless）**，必须靠外部记忆模块补持续性。
  → 与我们"LLM 无状态、状态是主体"完全同方向；但 CoALA 把 LLM 放核心，我们放边缘。
- **World Models for Cognitive Agents（arXiv:2506.00417）**：边缘智能视角下世界模型+
  认知代理综述，确认"世界模型是代理认知的支撑"这一框架。
- **Soar / ACT-R（经典，Laird; Anderson）**：记忆分型（working/episodic/semantic/
  procedural）+ 决策循环 + 符号操作的鼻祖。我们的 L0-L4 分层与之呼应，但我们用
  "训练的信号隔离"替代"符号规则"，这是本质差异。

## 2. JEPA / 能量模型家族（LeCun 线）

- I-JEPA(2023) → V-JEPA(2024) → V-JEPA 2；能量基模型（EBM）不考虑生成细节，只学
  "表征足够预测"。
- **AMI Labs 成立（2026-03）**：LeCun 离开 Meta 后获 6.5 亿美元创立，公开纲领即
  "对抗 LLM 缩放主路线的替代世界模型"。世界现存于 token 预测，AMI 主张"学习世界怎么
  运转的本质"。
- → 以自监督世界模型为架构主干这条路有资本级背书；"不与 Token 预测正面比精度"正是
  LeCun 也在走的位置。对我们的"宪法原则一"是外部背书。

## 3. Transformer / MoE 原理（对照系）

- **Transformer 原理本质**：对 KV 对做软寻址（softmax 内容寻址），O(N^2) 成本。
  能力来源即"全上下文精确索引 + 并行训练"。没有持久状态、没有目标、没有信念修正。
- **MoE 演进**：Switch → Mixtral 8x7B → DeepSeek V2/V3（细粒度专家切分、无辅助损失
  负载均衡、device-limited routing）。MoE 只是"参数稀疏路由"，在激活侧省算力，不改变
  无状态本质。
- → PLWM 不在同赛道竞争：我们拿的是"持久性/自适应/一次性校准"能力，不在上下文窗口
  上比长。对照方式必须是"同 compute 预算下、持续漂移世界"的考试，而不是 next-token
  PPL。

## 4. RNN 复兴（最直接的相关方）

- **Mamba / Mamba-2 / S4**：选择性状态空间模型，O(N) 训练、O(1) 推，固定态压缩。
  近年纯度 SSM 的共识弱势 = **精确检索弱、in-context 弱**（NVIDIA 混合扫描层+注意层
  就是为了恢复"从上下文复制字符串"能力）。
- **RWKV v6/v7**：线性注意力、动态递归，可 CPU 推理、edge 部署；v7 G1 2026 出。
- **混合系（Jamba 1.5 / Zamba / Falcon Mamba / Bamba / Codestral Mamba / Striped
  Hyena 2 / Liquid LFM 2）**：2025-2026 生产线事实是**纯 Mamba/RWKV 在短上下文输给
  Transformer，混合（SSM+注意）在长上下文赢**。混合化是生产主流，纯递归是少数。
- **几何上最接近我们的先例**：固定大小隐态的"持续状态"正是我们的递归核心，但 4 指出
  ——若状态只能压缩成单一矢量，会丢精确性。

→ **给 PLWM 的硬约束**：L1 世界模型内部的"循环隐态"要提供状态压缩 + 预测；L2 记忆必须
提供**精确的、可寻址的**内容存取，不能用单一隐态压缩替代，否则会落入 Mamba"持续但
只能模糊"的坑。我们的架构里"记忆读=地址优先级+槽内注意"正是为此设计的：既保留压缩
预测，又保留精确定位。**方向对，但必须写过"精确回放测试"。**

## 5. 大模型外的记忆

- **Memory3（arXiv:2407.01178, 2.4B, 2024）**："显式记忆"作为继参数隐式记忆、上下文
  工作记忆之后的第三种记忆。核心=记忆 circuitry 理论：把"具体知识"外化到可读写的
  explicative 记忆，参数只存"抽象知识"。2.4B 超过更大模型，且解码比 RAG 快。
  → 这是"知识在状态不在权重"在 LLM 界的直接同构证明！

- **Titans（arXiv:2501.00663, NeurIPS 2025）+ MIRAS（2504.13173）**：神经长期记忆模块，
  **在 test time 还继续学习**（MM 在任务中持续更新参数以编码未来）;用"输入梯度"衡量
  惊喜性（违反预期的时刻更容易被记下）;有 衰减/遗忘 机制;三种融入方式 MAC/MAG/MAL。
  缩放达 2M+ 上下文。MIRAS 把它统一进"online 优化=联想记忆=架构"的框架。
  → 三个 PLWM 决策被直接印证：
    1) surprise 驱动写入（我们用"训练出的预测误差"作写门，Titans 用"输入梯度"下的可选
       同思路，且都引用人类记忆的"惊喜更容易记"）;
    2) 记忆需要可遗忘（我们的伪随机学习/修正就兼遗忘）;
    3) test-time 持续读写记忆 = "状态主体"，不是推理时冻结。
  差异：Titans 仍是"注意+记忆"的混合 token 模型；我们把记忆作为行动层的一部分且整体
  目标不是语言建模，而是世界建模+行为。

- **CoALA 的记忆模块**（见 §1）; **Hindsight（2512.12818）**：把代理记忆结构化（世界
  事实/经历/实体摘要/持续信念）而不是只存对话，胜 RAG。
- **RAISE / MemoryLLM / MemLLM / RAG 系**：把记忆当工具/缓存，语义检索回代。

## 6. 世界模型（agent 主干）

- **DreamerV3（Nature 2025）**：RSSM（递归状态空间模型）编码观感，世界模型
  预测代表+奖励+继续，从想象中训练 actor-critic，150+ 任务单配置。是"状态世界模型+
  行为"被考虑的最权威先例。我们 L1/L3 的基本结构和它类，但：
  - DreamerV3 是"[:r ] 隐格做一切"单模型，我们分阶段+孤=不是同一条。
  - Rewarded 并发/奖励遮断不计在想象里，我们的"奖励只喂策略层"是更严格的声誉隔离。
- **Genie 3（DeepMind 2025-08）**：通用世界模型，实时 24fps/720p 交互，**一致性保持
  到分钟，视觉记忆回退 1 分钟**。明确的下一步 AGI 叙事=世界模拟+agent 训练地。
- **IRIS / TransDreamer / DIAMOND / EMERALD**：在 RSSM 之上换代 Token 化（ERMALD 2025
  在 Crafter 上 SOTA）。说明"世界模型可训练但用什么主干"仍无定论，我们的小状态 RNN
  主干并非无路可走。
- **Looped World Models（2026）**：把递归深度循环当作可学习的记忆，是对"反复循环用于
  模拟"的理论探索，与我们 L4 决策循环的短文呼应。
- **持续 RL+世界模型反馈（arXiv:2603.04029, 2026-03）**：**用世界模型预测残差做 OOD
  探测，检测到漂移就自动触发微调**，在四足机器人真机上验证。
  → 与我们"漂移世界考试 + 用预测误差判断世界是否变了 + 触发记忆/信念更新"完全一致。
  这是一个直接的、最新的外部印证。

## 7. 持续学习（漂移世界的考试学科）

- 主流：EWC/正则、参数化适配（LoRA, O-LoRA 正交子空间）、回放（replay）、
  Contextual Experience Replay (ICLR 2025, 净化上下文缓冲/免梯度，VisualWebArena
  +31.9%)、SuRe（惊喜驱动优先回放，2025-11）。
- **评估基准成熟**：MemoryAgentBench（ICLR 2026，能力=准确检索/学习/长程理解/选择性遗
 忘）; MemoryBench（从用户反馈日志学）；Evo-Memory（前向迁移/后向迁移分开测）。
- → 我们的"考试"可以直接借用这些基准构造的类似物，特别是**后向迁移**：漂移世界 100h
  前后各测一遍旧规则保持率，为"持续记忆是否真的不覆盖旧知识"的评估写法，行列的模板。

- CF 的解决路径我们的 depression 最核心 [线_自己的生机局]：**把世界知识放在外挂记忆里、
  参数只学抽象**（Memory3 同款），不确定层参数漂移导致的遗忘把"知识存储"搬到记忆库中，
  我们"知识在状态"由结构上避免。大参数持续学习（EWC/LoRA）即使网络再好也是手术式的
  缓解，我们是结构性回避。

## 8. 对 PLWM 设计的修订建议

在调研基础上对总设计的增量（不改路线，只加固）：

1. **L2 记忆读取增加"精确检索"体检**：不仅地址-priority+内容内注意。新增"从记忆槽中
   精确找回某一指定事实"的考试（类比在记忆库里找 needle）。若该考试过不了，往
   内容记忆形态（L2 槽体即 KV）与 Mamba 的教训贴近。
2. **总结出"惊喜门"共识**：write 门=预测误差(我们的方案) vs 参数梯度(size of grad,
   Titans) —两个都要，写入实验对照。若误差/梯度打架，记录证据。
3. **考试机制并入漂移考试科目**期末考试明确加入：遗忘考试（旧世界规律在漂移后保持率）
   + 记忆渗透。
4. **状态主体实验历史**：引 CoALA 的"LLM 无状态"作为我们"状态必须有结构化外部"的引文
  而非与我们竞争。
5. **修正一个措辞/承诺**：我们不说"Mamba 无优势说明 STM 压缩即可"，而要明确
  "有记忆的递归者 + 可寻址记忆槽 是共存关系"（已在 L2 设计中，要把这条写成
  rejection criterion：L2 不能只有单一隐态）。

## 9. 外部盘的对齐与反例

| PLWM 决策 | 外部共识 | 备忘 |
| --- | --- | --- |
| 状态主体 | 强支持（CoALA、Titans、Genie3、Memory3） | 主流的"核心还是 LLM" |
| 预测误差驱动写入 | 支持（Titans surprise；2603.04029 残差检测） | 需要"写门 vs 梯度"对照实验 |
| 奖励只喂策略层 | 无先例（DreamerV3 等在 WM 里学奖励预测） | 我们更强隔离,需自证 |
| 参数少+知识在状态/记忆里 | 支持（Memory3 外化具体知识得出 2.4B 胜过更大的） | Memory3 是最好的书面引证 |
| 纯递归状态足以 | 反例风险（Mamba 精确记忆弱） | 强制"可寻址读取" |
| 漂移世界作为试验场 | 支持（持续学习基准现成熟） | 别自行发明,借 MemoryAgentBench |
| 与 LLM 对比不是 PPL 而是行为 | 支持（世界模型主线都在行为评估） | Drift 世界的控制+预测两维都要 |
