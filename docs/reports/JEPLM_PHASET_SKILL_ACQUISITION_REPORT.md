## 一、合并循环(`experiments/arc/run_skill_acquisition_loop.py`)

用户把三条路(学习层扩展 / 自训练 / 向外获取)合并为**一条循环**:

```
【吸收】技能域 = 原语库(列表变换:double/square/reverse/sort/sum/evens/odds/negate)
  → 【练习】自训练环: 生成候选程序 → 自模型打分
            → 显式核验证(【真的执行代码】, 对就对, 错就错) → 优化
  → 【探索】遇到池里解不了的题 → 向外获取缺失原语 → 验证 → 纳入
  → 回到【吸收】: 新原语成为能力 → 越滚越强
```

**关键**:技能用**执行**验证(代码能跑、输出对 = 真),不是模板匹配——零编造。

## 三、裁决

**PASS(3 seed):架构获得第一个技能——编程**——

1. **练习收敛**:自训练环(生成→自评分→**执行验证**→优化)让系统从乱猜学到每个问题的正确程序。
2. **自评分校准**(ECE 0.03-0.12):知道自己会/不会(元认知,可作后续训练信号)。
3. **向外解锁**:初始池缺 odds/negate,探索后获得——**技能缺口向外补**。
4. **执行真值**:代码能跑、输出对才算会——**无编造**(不像大模型可能"看似会写其实跑不了")。

**这是"技能支柱"的第一块**:从"知道水果"到"**会做一件技能性的事**"。合并循环(吸收+练习+探索)被证明是技能获取的机制。

## 四、诚实边界与下一步

1. **技能是简单程序**(单原语,非组合/多步)。真正的编程(组合、函数、模块)需原语组合 + 更大语料。
2. **语料是给的**:技能域的原语是设计的。让系统从更大代码语料**自己提炼**原语是下一步(吸收更自主)。
3. **验证是可执行的简单域**:真实软件验证(测试/类型/正确性)是更大工程。
4. **这是第一个技能**:编程、设计、分析等技能可同一循环获取(换语料 + 换验证)。
