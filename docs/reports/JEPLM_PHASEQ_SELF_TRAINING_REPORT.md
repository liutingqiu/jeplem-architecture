# 阶段 Q 报告——自训练闭环:系统自己训练自己(M5)

> 2026-08-16 · 用户愿景的实现:"让他自己去训练自己"。在架构完善(阶段 N 知识进元认知、阶段 P 感知进元认知)之后,自训练环第一次跑通。3 seed、真实 1.32 亿事实库。

---

## 一、闭环(`experiments/arc/run_self_training_loop.py`)

```
系统生成候选规则(视觉颜色规则 × 9 + 知识规则 × 1)
  → 自模型打分(预测"这个规则会不会对")
  → 知识验证(每个规则用知识库真值核对,密集信号)
  → 用验证结果训练自模型(优化)
  → 循环:提议最高分规则 → 验证 → 强化
  → 收敛:系统学会知识规则是对的,颜色规则是侥幸
```

**任务**:场景有随机颜色的对象,选"水果"。水果性是**语义的**(只有知识库知道);颜色规则是假捷径。系统必须**自己发现**知识规则才对。

## 三、裁决

**PASS(3 seed):系统自己训练了自己**——

1. **生成**:候选规则集(含假捷径颜色规则 + 真知识规则)。
2. **自模型打分**:从验证经验学习"哪类规则可靠"——校准良好(ECE 0.08-0.14)。
3. **知识验证**:每个规则用 1.32 亿事实库真值核对(密集信号)。
4. **优化收敛**:最终 100% 提议**知识规则**(知识规则主导 1.0)——**学会了正确的行为,没走假捷径**。

**这是自训练的完整形态**:生成 → 自评分 → 知识验证 → 优化 → 收敛。**被知识锚定,零漂移**(不会把侥幸的颜色规则当真理)。

## 四、诚实边界与下一步

1. **候选池是给的**:系统在给定候选里自训练。**自主生成新候选**(潜因创造/自我发现机制喂进候选池)是自然延伸——自训练 + 库成长。
2. **单任务域**:知识条件选择。更广任务域(推理/语言/感知)的自训练是扩展。
3. **验证依赖知识库**:知识覆盖不到的地方,自训练信号稀疏——诚实边界。
4. **这是原型**:完整 M5(架构自我指涉用于自身语言/推理训练)在此闭环之上扩展。
