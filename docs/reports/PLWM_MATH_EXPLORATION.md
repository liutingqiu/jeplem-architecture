## 〇、给所有会话的通用纪律（先读）

1. **只推演数学结构**：不写训练代码、不新建环境、不动现有仓库代码。允许写公式、伪代码、证明要点、复杂度分析。
2. **交付物唯一合法格式**：一段"数学裁决"（见每章末的『结论格式』），指出：证实 / 证伪 / 需要额外限定，并给可复算的依据（引理/公式/复杂度）。
3. **不许用「可能」「应该」这种词糊弄科学判断**：要么给出上限/下限/构造/反例，要么明确说"此问题在此条件下无定论"并给出边界。
4. **可自由使用符号**：把记忆、推理、自指形式化，是你这个任务的职责所在。
5. **禁止"顺利"**：如果发现前置假设不成立，直接指出来并给出反例，这比"算了半天得出姿势正确"更有价值。
6. 若某论需要补充假设，把它**显式列出**，且说明"该假设在工程上是否容易满足"。

## 卡1 — 记忆寻址的计算理论（Memory Addressing as Computation）

### 1.0 本卡要回答的总问题

> 在连续向量空间上，"把一条记忆存进去、日后按内容把它取出来"这件事，数学上到底是什么？给定一组写入，是否总能构造一个读出，让 system 查 content 就能找到 value？如果取不出，是可计算性限制，还是只是训练优化的问题？

### 1.1 数学对象定义

- **记忆空间**：有限维实向量空间的一个子集（如 `V = R^d`），或更一般流形。
- **记忆槽**：`Memory = {(k_i, v_i)}` ，`k_i` 为键、`v_i` 为值，有限集 `i=1..M`。
- **写入算子**：`Write(k, v) → 更新 memory 状态`（连续函数、可微可选）。
- **读出/寻址算子**：`Read(query) → value`。Content-based addressing：`Read(q) = Σ_i softmax(score(k_i, q))·v_i`（如注意）。
- **匹配度**：`score(k, q)` 为内积/余弦/距离的单调函数。

### 1.2 要证明/证伪的具体命题

- **P1a — 可分离性**：对任意有限记忆 `{(k_i,v_i)}`，若键是**不成对冲突**的（对任意 `i≠j`，`score(k_i, k_j) < score(k_i, k_i)`），那么存在一个 content-based read 能近似忠实地取出每个值（即每个 query 在其自身 key 处有最高权重）。给出这个"分离程度"的下界/上界。
- **P1b — 记忆容量的信息论上限**：给定维度 d、M 个槽、并允许 soft 寻址，容纳 M 上限是多少——即“它们能够被存进同一向量记忆且仍可分辨”的信息论边界（可能依赖 d 与 score 形式）。
- **P1c — 训练可得多性**：如果记忆本身是学习出来的（写/读权重通过梯度学），是否存在鲁棒记忆分布让随机内存 union 到"能寻址 → 决策链"的损失是可导的、且可局部最小化的？给一个可复算的收敛结构（指数衰减/线性）。

### 1.3 工程界面（供与后续对接）

- 输入输出是 `(batch, series)` 的实张量，键和值同一维度 d（可声明不同维）。
- 记忆槽有限固定（如 16），可 keras style attention（`Q·K^T`+softmax）。
- 只考虑单步 read=write，不含跨 episode 持久，不含优先级。

### 1.4 交付物

> 结论格式（必须含）：
> - 证实/证伪/需限定 的最终判定。
> - 若证真：给出 `P1a/b/c` 各自的条件与边界（公式 + 简要推导）。
> - 若证伪：给出反例（一个 2-3 维、2-3 槽内存示死例）。
> - 给出对工程的影响（"这告诉我们：记忆槽数量 vs 维度必须满足 X，训练需要 Y 的梯度干净度"）。

## 卡包 B — 检索与查询的计算 limit（Retrieval and Querying Limits）

### 2.0 问题定位

> 记忆不止"存+寻址"，还要有"按语义查询"。这类比于在一个隐空间里做**最近邻 + 组合检索**。我们要证明/证伪：给定有限记忆，能否总是构造一个查询函数，把"想找的东西"从记忆里可靠取出——即使查询是**模糊/部分**的。

### 2.1 数学对象

- **查询空间**：与键同空间 `Q ∋ q`，但 q 可能是一项的"部分信息"（如只给指纹、特征子集）。
- **检索目标**：找到那些 `v_i` 使得 `score(k_i, q)` 高，且 `q` 必须从语义上确定它。
- **组合检索**：`查询 f(记忆) = "能所有满足 P 的条目"`，即按谓词筛选（不是单个 top-1）。
- **哈希/多路索引**：可预设不同 score 函数构成"索引结构"。

### 2.2 要回答的命题

- **P2a — 模糊查询的可恢复性**：如果查询 q 是记忆某个键**有噪声变体**，是否总可恢复其值？何时不可（当两个键语义距离小于噪声）→ 给出"鉴可"边界。
- **P2b — 谓词筛的前提**：对"所有满足条件 P 的条目"，其并集检索是否需要额外索引（多 score 函数绑定）；给出最小索引维度 vs 存储条数关系（可等价为哈希/布隆过滤器的匹配）。
- **P2c — 一致性保障**：若记忆同时存矛盾 a 与 b（同 key、不同 value），查询返回什么——是否要引入"置信度/版本"，否则一致性不保？证明或给最小反例。

### 2.3 判例

- 上述均只关心单次查询，不做跨episode。
- 键空间允许语义相近（这是真实任务（如"人 VS 猴子"）对视维尔情况。
- 允许提供额外训练出的 score 函数族。

### 2.4 交付物

> 结论格式（必须含）：
> - P2a/P2b/P2c 各自判定 + 边界。
> - 若有不可解（如噪声不可分）给出反例和最小修复（加索引/加层次）。
> - 可计算复杂度：查询一次 O(?) 与存储 O(?) 的关系，说明"在 M 个槽时能承受"。

## 卡包 C — 推理的时间/代数结构（Reasoning as Algebra）

### 3.0 问题定位

> "真正的思考"不是查值，而是**把旧记忆组合成新结论**（如"猫 + 会捕鼠 → 猫会捕猫的自带新事实上确实不是原来的任意一条）。数学上，这让人想到：记忆上的**代数操作**（合并、封锁、多项组合）以及**时序结构**（先有 A 再有 B 才可得 C）。我们要替"推理"找它属于自己的**最小代数/时序表示**。

### 3.1 数学对象

- 把"事实"看作记忆条目（键+值），"推理"看作把若干条目**组成**一个新条目的运算符，记作，多输入多输出、可叠加。
- 三类候选代数：
  - **集合式/偏序**：一份子集，可证的都是闭合命题。若"能推出 C"当 C 属于某些推导的封闭包。
  - **张量/矩阵**：规则表是"乘法表"，C = 乘法/挠。但如果规则是"含 AND/OR/否"逻辑表也可能是布尔代数。
  - **层化（temporal）**：若推理依赖"先有 A 后有 B"，数学对象是**时序图/有向无环图（DAG）**，结论是路径合成。

### 3.2 要回答的命题

- **P3a — 表达式表示**：是否存在一个"事实"→“张量”的到位嵌入，使"组合推理 C = f(A,B)"成为张量中的某种乘法（结合？交换？），并且干净、可等。若要用"已知"之外的结构，必须给出反例。
- **P3b — 时间/顺序的必要性**：当结论依赖序（"A 后 B，才得 C；B 后 A 不得"），任何"忽略顺序的代数（交换的、纯集）"都会错。证明"顺序在组合推理中何时不可或缺"，并给出能表达的表示（如 DAG / 单步骤 `step` 状态）。
- **P3c — 从值到命题**：把"某个值 a 属于属性 P"（即谓词判断）与"用户通过改写值的条件"是不是都能统一成一个结构，使"价值表达 + 规则公理"一起被纳入"记忆上的推理"，且仍保持数学一致性。

### 3.3 判例

- 只考虑"组合"（合成新事实），不考虑环境不确定性。等价，提供反例优先。
- 推理算子可以有参数（不可知的可学习权重）。

### 3.4 交付物

> 结论格式（必须含）：
> - 三选一：证实（给出表示与等价的证明要点）/ 证伪（给出反例）/ 需要额外假设（哪些、是否可）。
> - 若证：给出适用的代数结构名称（半群？偏序？DAG 幂集）与一条必导入的恒等式（如 `f(f(A,B),C)=f(A,f(B,C))` 成立/不成立）。
> - 工程启示：这决定我们的记忆槽是否要携带"关系/顺序/谓词"之外的注册，还是纯值即可。

## 卡包 D — 冲突、修订与稳健性（冲突，修订，自纠错）

### 4.0 问题定位

> 自指的核心：当新事实与旧记忆冲突，能**被发现并修订**，且这种行为在数学上**稳定**（不会反复倒、不会被旧记忆反吞噬、不无限循环）。把"修订"形式化为一个算子 `Rev: (旧M, 新证据) → 新M`，问它需要什么性质才能保证收敛到一致而理性。

### 4.1 数学对象

- 记忆 `M ={(k,v,c,t)}`：c = 断言强度/置信度、t = 时间（或单调计数器）。
- 冲突定义：存在同key但 value 相异、且各自 c 高的条目。
- 修订算子 `U`：输入旧记忆全部 + 一条新（k, v, c, t），输出新记忆。
- 性质命题：**收敛性**、**单调性**、**不变引入假**（不会无中生有）、**最小变化**（只改冲突条，不动其他）。

### 4.2 要回答的命题

- **P4a — 修订收敛**：给出 `U` 的具体形式（如按置信度的贝叶斯式合并、或按时间戳优先的覆盖、或保留双方的"版本共存"），并证明：重复施加相同冲突证据若干次后，记忆到达一致状态（固定点），不走环。给出固定点是否存在或反例。
- **P4b — 同时保持“旧有用”与“新准确”**：证明或反证：修订后"已旧且未被推翻"的记忆应保留；"被新推翻"应删除或降置信度。这对应**单调一致性**；给条件。
- **P4c — 错误如何被识**：在纯记忆层面，冲突的检测 = 判定"两条记忆是否对同一密钥给出不一致结论"。这是**可计算**吗？同上卡 P2c 但升级成"时间演化 + 证据累积"后的版本。给判据。

### 4.3 判例

- 模型内部只有记忆状态与置信度/时间戳——讨论**会不会崩**相比真实数据更核心。
- 注意力集中在"修订这一单一操作"，可为多个算子逐一比较。

### 4.4 交付物

> 结论格式：
> - `U` 候选算子清单（给 2-3 个不同修订规则）+ 对每个：收敛/单调/最小变化的证明或反例。
> - 推荐一个"在数学上最安全"的算子（用「证据强度/时间戳 → 覆盖 vs 共存」可保证单调 + 收敛）。
> - 工程启示：这决定了自指纠错的神经模块是否有稳定梯度（不因修订产生环路）。
