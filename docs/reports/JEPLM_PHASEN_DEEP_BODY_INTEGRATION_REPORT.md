## 一、深度在哪(`experiments/arc/run_deep_body_integration.py`)

v17 的 meta-router 在记忆/信念之间路由。阶段 N 扩展到**三源**:

```
三状态(不同观测动力学,使特征可分):
  s=0 记忆   :观测值稳定 0 → 记忆总是正确
  s=1 信念   :观测值翻转 0→1 → 信念更新后正确
  s=2 知识   :观测值是噪声(信念/记忆不可靠)→ 正确答案来自知识库

【知识通道】对每个查询给出语义答案(k_v = "是水果吗",真实 Wikidata)
  → 【meta-router】输入 状态特征 + 三源答案值(mem_v/bel_v/k_v),
          学习"哪个源可信"——知识是第三路由选项(不是托管任务)
  → 【self-model】预测路由后答案的正确性(对 信念+记忆+知识 合成推理的元认知)
  → 【账本】每个路由决策 + 置信写共享账本
```

## 三、裁决

**PASS(3 seed):知识耦合进身体的元认知回路**——

1. **router 学会何时信任知识**:知识状态 100% 路由到知识源——不是托管调用,是**元认知决策**(与记忆/信念并列的选项)。
2. **self-model 覆盖合成推理**:预测"信念+记忆+知识"路由答案的正确性,ECE 0.15-0.20(校准良好)。
3. **账本**:每个路由决策带置信 + 溯源。

**这是"架构完善"的关键一步**:知识从"被调用的工具"变成"**参与身体自我认知的源**"——系统知道何时该用知识(元认知),也知道自己的合成推理有多可信(自模型)。**不是托管,是耦合。**

## 四、诚实边界与下一步

1. **设计含显式状态类型**:router 学到"哪种状态→哪个源"。更开放的自适应(知识作为普遍源,动态权衡)是进一步。
2. **self-ECE 0.15-0.20**:校准良好但非完美——更大 self-head / 更多数据可改善。
3. **感知未进此环**:感知→知识的桥(阶段 H)与此元认知环的合体是下一步(完整架构)。
