# 阶段六 ARC 集成报告——机制 × 真实经验库成长集成(#44)

> 日期:2026-08-15 · 纪律:预写达标线、3 seed、诚实负结果、零假事实约束。
> 定位:阶段六总裁决预告的"下一步决战"——把 G1-G4 机制并回真实经验,看真实 ARC 覆盖能否动。**记录型里程碑(M5:真实 ARC 覆盖仅记录,验收非目标)。**

---

## 一、背景:决战的预设

阶段六总裁决:机制在受控域成立(G1-G4 全过),但真实 ARC 覆盖未变(G5 记录:训练 3.25% / 评估 0.25%,为 pre-G1a 历史数;**当前静态基线 post-G1a = 5.2% train / 0.5% eval**,见 `arc1-coverage-current.json`)。决战 = **机制 × 真实经验库成长集成**——潜因创造(M2)/流形(O1)/学习层 schema(G1)/知识驱动(G4)应用到真实 ARC 任务,测覆盖是否动。

**判据**:零假事实(被确认候选不得在测试上错);覆盖提升诚实记录(不设通过门,M5 记录型)。

## 二、Part A——潜因创造 × 真实 ARC 覆盖(决定性测量)

**脚本**:`experiments/arc/run_arc_integration.py --part A`。对 800 个真实 ARC-1 任务(训练+评估),先跑静态原语库(`induction.search_program`,阶段三封顶基线),失败的任务走潜因管线:`manifold_generate`(翻转/旋转+重着色)→ custom 颜色潜因(新颜色函数)→ permutation 潜因(新置换),每个候选经显式核 `adjudicate` 确认,确认后在测试上打分。

**结果(3 seed 一致,零假事实)**:

| 文件 | 静态库 | 潜因边际 | 合计 | 假事实 |
|---|---|---|---|---|
| arc1_training (400) | 0.052 (21 任务) | **0.003 (1 任务)** | 0.055 | 0 |
| arc1_evaluation (400) | 0.005 (2 任务) | **0.000 (0 任务)** | 0.005 | 0 |

**裁决**:潜因创造(新颜色/新置换原语)在 400 个真实训练任务里**只多解 ~1 个任务**,评估 0 个;零假事实(3 seed 稳定)。**流形/潜因词汇几乎不覆盖真实 ARC 变换空间。**

## 三、Part B——body 集成(机制并回 body)

**脚本**:`run_arc_integration.py --part B`。潜因发现跑在 UnifiedBody 事件循环内(v18 模式),前 60 个真实 ARC 训练任务;确认的变换事实写共享账本;同时跑 v17 核心(信念/修订/路由/self-head)。

**结果(3 seed)**:

| seed | belief | revision | router | self-ECE | arc 命中 | ledger | 假事实 |
|---|---|---|---|---|---|---|---|
| 444 | 1.0 | ✓ | 1.0 | 0.001 | 0/60 | 0 | 0 |
| 555 | 1.0 | ✓ | 1.0 | 0.001 | 0/60 | 0 | 0 |
| 666 | 1.0 | ✓ | 1.0 | 0.001 | 0/60 | 0 | 0 |

**裁决**:机制**无干扰地共存**(v17 核心全保真,G3 回归成立),账本写入机制可用;但真实 ARC 任务**不触发**潜因发现(60 任务 0 命中,ledger 诚实为空)。

## 四、Part C——知识驱动潜因 × 真实 Wikidata(G4 移植)

**脚本**:`experiments/arc/run_knowledge_latent_cause.py`。G4(合成库)机制移植到真实 1.32 亿事实 Wikidata:混合关系传递潜因(子类 P279 + 实例 P31 → 推断新 instance-of),held-out 20% P31 边测恢复率,精确匹配基线=0。

**结果(3 seed)**:恢复率 **0.0002-0.0004**(39968 条 held-out 边恢复 7-15 条)。

**诊断**:仅 **0.7%** 的 instance-of 主体有任何 P279 子类边 → **真实 Wikidata 的 instance-of 是原子直连,不是组合结构**,潜因无证据可组合。

**裁决**:知识驱动潜因在合成结构数据上成立(G4 1.0),在真实 instance-of 上**几乎无组合可推导**(0.03%);但**同关系传递潜因(P279 链)在真实数据上 0.999**(G-K 已证)。→ 知识轴贡献的是传递推理潜因(已入引擎),不是原子事实潜因。

## 五、参照:学习层 schema 词汇(V1,既存)

`arc-v1-schema-ceiling.json`:对象级 schema 文法在真实 ARC union **6.0%**(400 任务,242s,base 21 + schema 边际)。学习层词汇也只把真实 ARC 从 ~5.3% 抬到 6.0%。

## 六、总裁决(#44)

**机制 × 真实经验库成长集成后,真实 ARC 覆盖上限仍 ~6%**:

| 机制词汇 | 真实 ARC 边际提升 |
|---|---|
| 静态原语库(阶段三基线) | 5.2% train / 0.5% eval |
| + 学习层 schema(G1) | +3-11 任务(union 6.0%) |
| + 潜因创造(M2/O1,流形+新颜色+新置换) | +1 任务 train / +0 eval |
| + 知识驱动潜因(G4→真实) | 传递推理已入引擎;instance-of 原子不可组合 |
| **合计** | **~6% 上限,零假事实** |

**三条诚实结论**:
1. **阶段六 G5 记录重申**:机制受控域成立(G1-G4 全过)≠ 真实 ARC 覆盖上升。真实 ARC 变换空间(位置映射/排列/抽取/对称/对象操作)远超任何手编机制词汇。
2. **终局证伪条件 4 候选坐实**:即使新原语创造(schema + 潜因)全上,结构词汇成长把真实 ARC 封在 ~6%——"结构成长到不了 AGI 广度"得到**进一步支持**(非最终,因知识轴刚开始)。
3. **零假事实贯穿**(3 seed 稳定):显式核 adjudication 在真实数据上不确认错误候选——诚实边界守住。

**诚实边界**:这不是机制失败——是**词汇广度与经验规模**的墙(阶段六"开放适应/词汇成长(世界级)依赖经验规模")。下一步真正的杠杆在**知识轴 × 网格世界模型的集成**(Phase-6 推动器 2:真实环境 + LLM 皮层生成经验),以及更大规模的网格变换词汇学习,而非手编机制。

**证据**:`artifacts/phase6-arc-integration.json`(Part A)、`phase6-arc-integration-body.json`(Part B)、`phase6-kb-latent-cause.json`(Part C)、`arc-v1-schema-ceiling.json`(V1 参照)+ `experiments/arc/{run_arc_integration,run_knowledge_latent_cause}.py`。
