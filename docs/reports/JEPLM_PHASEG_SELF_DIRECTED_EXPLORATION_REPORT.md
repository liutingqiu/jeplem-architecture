# 阶段 G 报告——自主探索闭环:系统自己决定探索什么、学什么

> 2026-08-15 · 自主发展(阶段 G)。回应用户两个要求的**合体**:(1) 系统基于现有知识**自己探索新知识**;(2) 这是**多模块集成**的行为,不是单链路。自主 + 知识 + 发现 + 自指 + 账本在一个循环里。3 seed、真实 1.32 亿事实库。

---

## 一、闭环(`experiments/arc/run_self_directed_exploration.py`)

```
【自主】对候选类别按"好奇度"打分(成员属性分布的熵 = 内部不确定度),
        优先探索最不确定的 —— 系统自己决定探索顺序
  → 【知识】从 KnowledgeStore 采样成员、收集属性
  → 【发现】归纳类别原型(≥60% 成员共享的属性)= 从未存储的新概括
  → 【自指】在 held-out 成员 vs 随机实体上验证;不泛化的假设被拒绝
  → 【账本】被接受的原型带溯源累积 —— 系统在长大
```

## 三、裁决

**PASS:系统自主探索自己的知识库,发现并验证新概括,累积为自身知识**——

1. **自主(目标设定)**:系统按好奇度(信息熵)自主决定先探索哪个类别——不是被喂清单,是自己排优先级。
2. **发现(归纳)**:从成员属性提炼类别原型("气象学家是人类")——库外的新概括。
3. **自指(验证/拒绝)**:原型在 held-out 上验证;不泛化的假设拒绝(机制存在;本池类别都较强,拒绝未触发)。
4. **账本(累积)**:被接受的知识带溯源写入,系统知识在探索中增长。

**这是"自己探索新知识" + "多模块集成"的实证**:一个自主→知识→发现→自指→账本的完整学习环。

## 四、诚实边界

1. **好奇度是"熵"(多样性)信号**:真实的好奇/新奇信号(稀有、异常、反直觉)是更强的方向——本版本用了可计算的替代。
2. **拒绝未触发**:候选类别都强(职业/类别有强共享属性);掺入噪声类别会触发拒绝——机制在位但没被压力测试。
3. **探索是单轮**:每个类别探索一次;多轮迭代(已学知识影响后续探索)是自然延伸。
4. **目标由熵驱动,非内生价值**:真实自主(目标来自价值/缺口,探针 B 的方式)是下一步。
